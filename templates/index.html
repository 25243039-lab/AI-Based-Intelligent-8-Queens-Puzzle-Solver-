🧠 Constraint Satisfaction Problem (CSP) Formulation

In Artificial Intelligence, the 8-Queens problem is a canonical benchmark for Constraint Satisfaction Problems (CSPs). A CSP is defined by a triplet \((X, D, C)\):

Variables (X)
X = {Q₀, Q₁, Q₂, ..., Q₇}

8 variables, where variable Qᵢ represents the queen located on Row i.

Domains (D)
Dᵢ = {0, 1, 2, 3, 4, 5, 6, 7}

The domain for each variable contains the 8 possible column indices for that row.

Constraints (C)
Qᵢ ≠ Qⱼ & |Qᵢ - Qⱼ| ≠ |i - j|

Row: Implicitly satisfied (1 queen/row).
Column: No two queens share column.
Diagonal: Slope \(\Delta y / \Delta x \neq \pm 1\).

🎓 Viva Voce & Oral Defense Preparation Guide

Standard questions asked by professors and examiners during project defense:

Because rather than searching for an optimal sequence of actions toward a path cost, a CSP is concerned purely with finding a state that satisfies a predefined set of constraints. In 8-Queens, variables are the 8 rows, values are the column positions, and constraints mandate no attacks along rows, columns, or diagonals.
On a 2D Cartesian grid, any line at a 45° diagonal angle has a slope \(m = \Delta y / \Delta x = \pm 1\). Therefore, \(\frac{y_2 - y_1}{x_2 - x_1} = \pm 1\), which rearranges to \(|y_2 - y_1| = |x_2 - x_1|\). In our representation, row index is \(x\) and column index is \(y\), so two queens at \((i, Q_i)\) and \((j, Q_j)\) conflict along a diagonal if and only if \(|Q_i - Q_j| = |i - j|\).
Pruning means rejecting an entire subtree of the state space tree as soon as a partial assignment violates any constraint. If placing a queen at row 2, col 1 causes a conflict with row 1, backtracking immediately stops exploring any placements for rows 3 through 8 under that branch, eliminating thousands of pointless evaluations in a single step.
There are exactly 92 distinct solutions. If rotational and reflective symmetries (isomorphisms) are factored out, there are 12 fundamental solutions. Our AI solver finds and allows you to view all 92 distinct solutions.
Time Complexity: Upper bound is \(O(N!)\) because each row placed leaves at most \(N-1, N-2, \dots\) valid choices, but the effective branching factor is drastically lower due to aggressive pruning. In our 8-Queens solver, the first solution is found after just 876 node evaluations.
Space Complexity: \(O(N)\) auxiliary stack space, since the recursion depth is at most \(N\) rows.
